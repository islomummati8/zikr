# Zikr

This repository contains the Zikr Flutter app (prayer times, dhikr, habits, analytics).

Privacy policy
---------------
A bilingual Privacy Policy (English + Russian) is available in the repository and ready for GitHub Pages:

- docs/privacy-policy.html

To publish the policy on GitHub Pages:
1. Ensure this file exists at `docs/privacy-policy.html` in the repository root.
2. Open the repository Settings → Pages.
3. Under "Source" select the branch `main` (or your default branch) and folder `/docs`.
4. Save. After a few minutes the site will be available at `https://<your-username>.github.io/<repo>/privacy-policy.html`.
